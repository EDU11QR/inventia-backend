# 🚀 INVENTIA - Inventory Management System

INVENTIA es un sistema de inventario inteligente diseñado para pequeñas y medianas empresas.

## 🧠 Funcionalidades

- Gestión de productos
- Registro de ventas
- Control de stock
- Alertas de inventario
- Reportes y métricas

## ⚙️ Tecnologías

- Java + Spring Boot
- MySQL
- React + Vite (frontend)
- REST API
